### **Homebrew** {#homebrew}

[Homebrew](https://brew.sh/index_zh-tw) is a package manager for macOS. It lets you download, install, update, and remove software from the terminal, and it handles dependencies automatically, which makes it very convenient. Before installing packages with it, install Homebrew itself by running:

```shell
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

After installation, remember to run these two lines to add Homebrew to your PATH:

```shell
# Write the environment setup for /opt/homebrew/bin/brew to /Users/boshkuo/.zprofile so it loads automatically in each Bash shell session.
(echo; echo 'eval "$(/opt/homebrew/bin/brew shellenv)"') >> /Users/{Your user name}/.zprofile

# Run the environment setup for /opt/homebrew/bin/brew to apply the variables to the current Bash shell.
eval "$(/opt/homebrew/bin/brew shellenv)"
```

You can now install packages with `brew`. To install wget, for example, run:

```shell
brew install wget
```

This tells Homebrew to download and install wget. If you've already installed it, Homebrew checks for an update and brings it up to the latest version.

### **iTerm2** {#iterm2}

[iTerm2](https://iterm2.com/) is a popular terminal application for macOS. Compared with the built-in Terminal, it offers more features and customization options. You can change the font, background image, text colors, and other appearance settings to suit your preferences. It also supports saving and sharing themes and layouts, making it easy to share a setup you like or use someone else's.

Another feature that drew me to iTerm2 was its tab and window management. It can split panes and open multiple terminals, much like tmux. I wrote about this in [iTerm2 Tips: Shortcuts for Working More Efficiently](https://notes.boshkuo.com/docs/DevTools/Terminal/iterm-shortcut-key).

### **Oh My Zsh and Powerlevel10k** {#oh-my-zsh-and-powerlevel10k}

[Oh My Zsh](https://ohmyz.sh/) is a framework built around the Zsh shell, with plenty of terminal features and tools. It makes it easy to customize the terminal's appearance and behavior and work more efficiently. It has a range of themes, with [Powerlevel10k](https://github.com/romkatv/powerlevel10k#manual) being one of the most popular. Besides looking good, it offers useful features such as showing the current Git branch and highlighting errors. Oh My Zsh also has plugins for completion, recalling commands, quickly switching directories, and more. They can save quite a bit of time in everyday terminal work.

- **A complete Oh My Zsh + Powerlevel10k setup guide**
  - My main reference was [Setting Up a Good-looking, Practical Command Line with Oh My Zsh + Powerlevel10k](https://holychung.github.io/2020/12/24/%E3%80%90%E5%88%86%E4%BA%AB%E3%80%91Oh-My-Zsh-powerlevel10k-%E5%BF%AB%E9%80%9F%E6%89%93%E9%80%A0%E5%A5%BD%E7%9C%8B%E5%A5%BD%E7%94%A8%E7%9A%84-command-line-%E7%92%B0%E5%A2%83/). It gives a good overview of installation and how to configure the relevant files.

- **Oh My Zsh plugins**
  - **[zsh-completions](https://github.com/zsh-users/zsh-completions):** Follow the [oh-my-zsh](https://github.com/zsh-users/zsh-completions#oh-my-zsh) installation instructions.
  - **[zsh-autosuggestions](https://github.com/zsh-users/zsh-autosuggestions):** Follow the [oh-my-zsh](https://github.com/zsh-users/zsh-autosuggestions/blob/master/INSTALL.md#oh-my-zsh) installation instructions.

- **My installation notes**
  - Install Oh My Zsh:

    ```shell
    sh -c "$(curl -fsSL https://raw.githubusercontent.com/ohmyzsh/ohmyzsh/master/tools/install.sh)"
    ```

  - Install Powerlevel10k using the officially recommended method for Oh My Zsh:

    ```shell
    git clone --depth=1 https://github.com/romkatv/powerlevel10k.git ${ZSH_CUSTOM:-$HOME/.oh-my-zsh/custom}/themes/powerlevel10k
    ```

  - Add this line to `.zshrc` to switch to the Powerlevel10k theme you just installed:

    ```shell
    ZSH_THEME="powerlevel10k/powerlevel10k"
    ```

  - Reload the Zsh configuration:

    ```shell
    source ~/.zshrc
    ```

- **My Powerlevel10k configuration**
  - Run this command to configure the theme to your liking:

    ```shell
    p10k configure
    ```

  - My Node.js version and icon weren't showing up, so I edited `.p10k.zsh` to adjust a few Powerlevel10k settings. I enabled `node_version` manually and changed the Node.js icon and colors. You can find icons in the [Cheat Sheet](https://www.nerdfonts.com/cheat-sheet).

    ```shell
    # Show node_version()
    typeset -g POWERLEVEL9K_RIGHT_PROMPT_ELEMENTS=(
        ...
        node_version            # node.js version
    )
    ```

    ```shell
    ##############################[ node_version: node.js version ]###############################
    # Node version color.
    typeset -g POWERLEVEL9K_NODE_VERSION_FOREGROUND=240
    typeset -g POWERLEVEL9K_NODE_VERSION_BACKGROUND=230
    # Show node version only when in a directory tree containing package.json.
    typeset -g POWERLEVEL9K_NODE_VERSION_PROJECT_ONLY=false
    # Custom icon.
    # typeset -g POWERLEVEL9K_NODE_VERSION_VISUAL_IDENTIFIER_EXPANSION='⭐'
    typeset -g POWERLEVEL9K_NODE_ICON='\uF898'
    ```

- **Issue**
  - When I first opened VSCode's terminal after setting this up, the icons didn't display properly and some characters were garbled. The terminal font was incompatible with Powerlevel10k. Following [Setting Up a Nice Terminal in VSCode with Zsh + Powerlevel10k](https://sasacode.wordpress.com/2021/06/18/%E5%9C%A8vscode-%E8%A3%9D%E5%80%8B%E6%BC%82%E4%BA%AE%E7%9A%84-terminal-%E4%BB%8B%E9%9D%A2-zsh-powerlevel10k/) and changing the terminal font to `MesloLGS NF` fixed it!
